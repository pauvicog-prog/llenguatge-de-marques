# ASIX1 - Llenguatges de Marques (0373)

Repositori amb les pràctiques d'HTML5 i CSS3 realitzades durant el curs.

## Estructura del repositori

* **`01-exercicis-html5/`**: Recull dels 12 exercicis pràctics d'estructura bàsica, semàntica, llistes, taules, multimèdia, enllaços i formularis en HTML5.
* **`02-correccio-errors/`**: Pràctica de depuració i correcció semàntica (`tortugues.html`) validada amb el validador oficial del W3C.
* **`03-horari-html/`**: Horari setmanal de classe estructurat mitjançant taules HTML.
* **`04-karma-web-responsive/`**: Maquetació responsive (escriptori i mòbil) de la landing page de Karma amb HTML5 i CSS3.
